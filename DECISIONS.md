# Decision Log

## D-001 — Code-native ecosystem board

**Decision:** Build the interactive ecosystem with semantic HTML, CSS, and SVG rather than placing the interaction inside a canvas or generated image.

**Reason:** The board must remain responsive, keyboard-operable, screen-reader-readable, and maintainable by different coding agents.

## D-002 — One distinct mechanic per technoskeptical question

**Decision:** Each of the five questions uses a different interaction pattern.

**Reason:** Repeating multiple-choice cards would weaken engagement and obscure the distinct intellectual work performed by each question.

## D-003 — Evidence tokens instead of a single “good technology” score

**Decision:** Players collect five evidence tokens and see several transparent system indicators rather than receiving a binary approval score.

**Reason:** Technoskepticism is a stance of inquiry, not an automatic verdict. A single score would falsely imply that complex technologies can be universally ranked.

## D-004 — Four replayable school scenarios

**Decision:** Include AI writing, automated tutoring, predictive attendance, and phone-management proposals.

**Reason:** The common five-question structure becomes clearer when players can see how different technologies produce different trade-offs and dependencies.

## D-005 — Generated art is atmospheric, not evidentiary

**Decision:** Use one original generated hero illustration while keeping all consequential information code-native.

**Reason:** The game should feel visually rich without making a bitmap responsible for interaction, accessibility, or factual communication.
